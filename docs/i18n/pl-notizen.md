# Polski: Entscheidungen

- **Anrede:** ty (Du-Form), in Sätzen direkt an die Person groß geschrieben („Ci przypomnę“, „Twój plan“)
- **Schulbegriffe:** zadanie domowe · sprawdzian · kartkówka
- Vier Mehrzahlformen: `#one`, `#few`, `#many`, `#other` (Intl.PluralRules).
- Anredeformen („Ty/Ci/Cię/Twój“) werden groß geschrieben, wie in Briefen und Nachrichten an eine Einzelperson üblich.
- Geschlechtsneutral: *Czy coś mi umknęło?*, *Jeśli to nie Ty…*
- Stella schreibt von sich weiblich: *zapisałam, zauważyłam*.

## Ton-Beispiele (aus dem Katalog)

- nett: Zapisane! Jutro o 19:00 Ci przypomnę. 💫
- frech: Znowu łacina? No dobra, zapisane. Jutro o 19:00 będę Cię męczyć.
- cool: Spoko. Wpisane, przypomnienie jutro o 19:00.
