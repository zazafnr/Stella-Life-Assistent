# .brain-inbox

Briefkasten für das Projektgedächtnis **Stella-Brain**, wenn eine Claude-Sitzung den Vault nicht direkt pushen kann (Cloud).

- Eine Datei je Arbeit: `YYYY-MM-DD-thema.md` – kurz: was wurde geändert, welche Dateien, was ist offen, welche Entscheidung.
- Mit dem normalen Commit/PR mitschicken. Nach dem Merge holt die Action im Vault-Repo die Datei nach `Log/Inbox/`,
  die nächste lokale Sitzung arbeitet sie in die Notizen ein.
- Keine Schlüssel oder Passwörter hier hinein – dieses Repo ist öffentlich.
